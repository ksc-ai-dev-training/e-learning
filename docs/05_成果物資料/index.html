1. はじめに

1.1 本書の位置づけ

本書は、社内学習管理システム（コードネーム: Manabi）の要求仕様書（v1.0）・要件定義書（v1.20）・基本設計書（v1.26）で定めた機能（F-01〜F-29）・画面（S-01〜S-19）・API（A-01〜A-80）・テーブル（T-01〜T-29）を、実装可能なレベルまで網羅的に詳細化するものである。対象読者は本システムの実装担当者とする。

  • ID体系（REQ-xx=要求 / F-xx=機能 / S-xx=画面 / T-xx=テーブル / A-xx=API）は要求仕様書・要件定義書・基本設計書と共通であり、本書ではIDを用いて相互参照する。廃止・欠番のIDは基本設計書の扱いをそのまま引き継ぐ（F-03, F-07, F-27／S-07, S-18／T-02, T-05, T-07, T-24, T-25／A-05〜A-08, A-23〜A-26, A-68〜A-70）。
  • 上流文書は要求仕様書（docs/01_要求仕様書.html）・要件定義書（docs/02_要件定義書.html）・基本設計書（docs/04_基本設計書.html）の3文書とする。
  • 技術スタックは既存システム LCC CRM・Keireki を踏襲する（REQ-N-06）。Frontend: React 19 + TypeScript + Vite 6 + Tailwind CSS 4 + react-router 7 + SWR + Lucide React、Backend: FastAPI (Python 3.10+) + Uvicorn + asyncpg、Database: PostgreSQL (Supabase)、ファイルストレージ: Supabase Storage、AI連携: Anthropic Claude API（Messages API）、通知: Slack Incoming Webhook、ホスティング: Koyeb。
  • 本書は実装担当者がそのまま実装に移せることを目的とし、機能・画面・API・テーブルを網羅する。CRUD系のように処理が定型的なものは記載を簡潔にするが、対象から省略することはしない。
  • 各テーブルのカラム詳細（型・NULL可否・制約・既定値の全定義）、API詳細、画面項目定義、教材連携・AI機能の実装レベルの仕様は本書で定める。画面レイアウトそのものは画面モックアップ「03_画面モックアップ/」を正とし、本書では重複して図示しない。
