e-learning 画面モックアップ一覧

社内学習管理システム（e-learning）の画面モックアップ（静的HTML）です。各カードをクリックすると画面イメージを確認できます。
Ver 1.2 ／ 要件定義書 v1.5 に基づき更新（システムロールを member/admin の2種に統合、部署の概念を廃止、教材は必ずいずれかのプロジェクトに属する方式に一本化。画面一覧・画面遷移は要件定義書 4.1・4.2、基本設計書 4章 準拠）
※ 設計時点のイメージです。デザインシステムは Keireki（社員経歴書管理システム）のモックアップを踏襲しています。

S-01 ログイン
全員（未認証）

Googleでログインボタンのみのシンプルな画面。許可ドメイン（kogasoftware.com）のみ利用可。
S-02 マイ学習
全員

ログイン後の初期画面。自分が受けるべき必修・任意教材の一覧と進捗状況を表示。期限が近い必修教材を強調表示。
S-03 教材一覧・検索
全員

公開されている教材の一覧・検索。単元・コース単位で表示し、必修/任意・所要時間を確認できる。
S-04 教材受講
対象者（全員）

教材本文の閲覧、選択式・記述式問題への回答。中断・再開、反復演習・誤答抽出出題にタブで対応。
S-05 教材編集
対象教材が紐づくプロジェクトの管理者・編集者 admin

教材・問題のテキスト編集（Markdown/HTML切替）、ファイル・リンク添付、単元/コース構成、プロジェクトメンバーの確認とS-12への導線、AIレビュー結果・改訂履歴の確認。教材は必ずいずれかのプロジェクトに属するため（F-25）、アクセス可否は常にプロジェクトのローカルロールで判定されます。
S-06 配信設定
admin 対象プロジェクトの管理者

教材の配信対象（全社/プロジェクト/個人）、必修/任意、受講期限の設定。全社スコープはadmin、プロジェクトスコープは対象プロジェクトの管理者も設定可能。
S-07 組織管理 廃止（v1.5）
画面ID欠番

要件定義書v1.5で廃止。部署（department）の概念をシステムから廃止したため、部署登録を行う本画面自体が不要になりました。プロジェクトの作成・管理はS-11・S-12を参照。
S-08 受講状況ダッシュボード
admin 対象プロジェクトの管理者

担当範囲（プロジェクト/全社）の受講率・合格率・未受講者の確認。AI組織レポートの表示。admin は全社スコープ、対象プロジェクトの管理者は自プロジェクトのスコープに限定。
S-09 個人学習レポート
本人 対象者が所属するプロジェクトの管理者 admin

AIによる個人フィードバック（理解不足点・推奨教材）と学習履歴の表示。
S-10 管理
admin

タブ構成: 「ユーザー管理」（ロール変更・有効/無効）、「システム設定」（AI利用設定・Slack通知・猶予期間）。
S-11 プロジェクト作成
全員

プロジェクト名・説明を入力して新規作成するシンプルな画面。作成者は自動的にそのプロジェクトの管理者になる（F-24、v1.4新設）。
S-12 プロジェクト管理
対象プロジェクトの管理者 admin

タブ構成: 「プロジェクト情報」（名称・説明の編集）、「メンバー管理」（メンバー一覧・ロール設定・追加削除）、「教材の共有」（他プロジェクトへの共有設定）。F-24〜F-26、v1.4新設。
