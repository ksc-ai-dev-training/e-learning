受講する
マイ学習— ログイン後の最初の画面

自分の必修・任意教材の進捗、期限が近い必修教材、採点結果の更新、学習履歴をまとめて確認する画面です。

  1. 「必修・任意」タブで、期限が近い必修教材（赤枠で強調）を優先して受講する。
  2. 任意教材は興味のあるものを選んで「受講を開始」。
  3. 教材名・タグでその場検索して絞り込める。
  4. 新しい教材を探して登録したい場合は右上の「新しい教材を探す」から教材一覧・検索へ。
対象: 全員
教材一覧・検索

自分が参加しているプロジェクトの公開済み教材をキーワード・タグ・区分で横断検索します。

  1. キーワード・タグ・必修/任意の区分で絞り込み、「検索」を押す。
  2. 任意教材は「マイ学習に追加」でマイ学習にも表示されるようになる。
  3. 教材を開くと目次（章・ページ）が表示され、そのまま受講できる。
対象: 全員
個人学習レポート

自分（または管理しているプロジェクトのメンバー）の受講済み教材・スコア・合否をまとめて振り返る画面です。

  1. 「AIフィードバックを生成する」で、理解不足の分野・おすすめ教材のコメントを作成できる。
  2. 学習履歴の各行から「進捗リセット」（未受講に戻す。受験記録は残る）と「履歴から削除」（採点結果・AI集計から見えなくする）ができる。どちらも再受験回数の上限には影響しない。
対象: 全員（他人の分はプロジェクト管理者・システムadminのみ閲覧可）
プロフィール編集・Claude Code連携— サイドバー下部の「プロフィール編集」から

表示名・アイコンの変更に加え、Claude Codeから教材を作成・編集するためのAPIキーを発行できます。

  1. 「APIキー（Claude Code連携）」パネルから鍵を発行する（このとき限りしか表示されないのでコピーする）。
  2. 自分の端末のターミナルで、発行された鍵を使って claude mcp add コマンドを1回だけ実行する。
  3. 以後は「Manabiに新しい教材を作って」「教材ID◯◯を直して」のように自然な言葉で依頼できる。
対象: 全員
教材を作る
教材作成・編集— プロジェクト選択 → 教材一覧 → 目次編集 → ページ編集

教材の章・ページ構成の組み立て、本文・設問の入力、合否条件やAI採点の既定値を設定します。

  1. プロジェクトを選び、「＋新規教材を作成」（既存教材を直す場合は一覧から「編集する」）。
  2. 「目次編集」タブで章・小見出し・ページを追加し、各ページの「編集する」で本文・設問を入力する。
  3. 合格基準・再受験可否・再受験回数の上限を設定する。
  4. 下書き保存で確認し、問題なければ「公開する」（配信設定の確認モーダルを経由）。
  5. 教材が育ってきたら「問題一覧」タブで正答率の低い設問を見つけ、S-19の詳細画面で回答傾向を確認できる。
対象: プロジェクトの編集者・管理者
採点

記述式・コード記述式のうち「手動採点」設定の回答をまとめて採点するための、自分の担当教材を横断した一覧です。

  1. 受験記録カード（受講者×提出日）をクリックすると、その回のすべての未採点設問がまとめて開く。
  2. 設問ごとに正誤・フィードバックを入力すると自動保存される。
  3. すべて判定し終えたら「採点結果を送信」で受講者に公開する。
対象: 教材の作成者、全社ライブラリ必修教材はプロジェクト管理者も可
配信設定

教材ごとに必修対象・受講期限を設定する画面です（プロジェクトメンバーであれば任意教材は既に受講できるため、ここで設定するのは「誰を必修にするか」のみです）。

  1. 対象教材の行を選び、「プロジェクト全体に必修として配信する」または個人を追加指定する。
  2. 必修にすると受講期限を設定でき、マイ学習に期限付きで表示されるようになる。
  3. アーカイブ済み教材の状態確認・復元もこの画面から行える。
対象: 教材が属するプロジェクトの編集者・管理者、システムadmin
プロジェクトを運営する
プロジェクト作成

新しいプロジェクトを作成します。作成した人が自動的にそのプロジェクトの管理者になります。

  1. プロジェクト名・説明を入力し、内容を確認してから作成する。
対象: 全員
プロジェクト管理

プロジェクト情報の編集、メンバーの招待・ロール変更、他プロジェクトとの教材共有を行う画面です。

  1. 「メンバー管理」タブで社員を検索して追加し、管理者/編集者/受講者のロールを設定する。
  2. 「教材の共有」タブで、公開済み教材を他プロジェクトへ共有申請できる（下書きは共有不可）。
  3. Slack通知を使うには、「プロジェクト情報」タブでIncoming Webhook URLを登録し、「必修教材のリマインドをSlackに送信」を押す（個人名は含まれない）。
  4. 条件を満たす（教材が0件または下書きのみ・自分以外のメンバーがいない）場合のみ「プロジェクトを削除」が有効になる。
対象: 対象プロジェクトの管理者、システムadmin（一般メンバーは閲覧のみ）
必修教材受講ダッシュボード

プロジェクト単位で必修教材の受講率・合格率・未受講者を確認し、AIによる組織向け所見を生成できます。

  1. 担当範囲（管理者であるプロジェクト）を選択する。
  2. 「必修教材のリマインドをSlackに送信」で、そのプロジェクトのSlackチャンネルへ未受講件数をまとめて通知する。
  3. 「AI組織レポートを生成」で受講状況の所見コメントを作成できる。
対象: 対象プロジェクトの管理者、システムadmin
システム管理
システム管理

全社員のロール・有効/無効の管理と、AI利用状況・Slack通知などのシステム設定を行います。

  1. 「ユーザー管理」タブでロール変更・アカウントの無効化を行う（システムadminが0人になる変更はブロックされる）。
  2. 「管理者になっているプロジェクト」列から、そのままプロジェクト管理画面へ遷移できる。
  3. 「システム設定」タブで、今月のAI利用状況（機能別の呼び出し件数・概算コスト）やSlack通知先を確認する。
対象: システムadminのみ
