教材編集：Claude Code下書き作成

廃止（v1.20） S-18
この画面は基本設計書v1.20で廃止されました。
F-27（AI教材作成アシスト。ブラウザ内対話生成）の廃止に伴い、この画面も廃止されました。F-27はe-learningのバックエンドがAnthropic Claude APIを直接呼び出す構造のため、利用のたびにe-learning側で従量課金が発生していました。代替のF-05（Claude Code CLI連携）はClaude Code利用者本人の契約・APIキーで課金され、e-learning側の運用コストは発生しません。「AIが教材の目次・ページ・問題を対話的に作成する」という似た体験を提供する2つの経路のうち、コストの発生しないF-05に一本化することとしました。

教材の作成・修正へのAI支援は、すべてClaude Code CLI（F-05、8章参照）を通じて行ってください。

S-14「＋新規教材を作成」は、この画面を経由せず空のS-05（目次編集）画面へ直接遷移します。既存教材の改善はS-05・S-17を直接開いて編集してください。

画面ID・パス（/materials/draft-sessions/:sessionId）・関連API（A-68〜A-70）・関連テーブル（T-24 ai_draft_sessions・T-25 ai_draft_messages）はいずれも欠番として保持し、本モックアップのファイルも参照用に残しています（基本設計書4.7b節・5.28節参照）。
旧仕様（Claude Codeとの対話でブラウザ内で教材の下書きを作成する画面としてのS-18）のレイアウトは、本改訂前のリビジョン（v1.19以前）を参照してください。
