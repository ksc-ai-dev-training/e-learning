ブランチを作成する

作業を始める前に、必ず main から新しいブランチを作成します。

git checkout -b feature/add-login

プルリクエストを作成する

変更をコミットしたら、リモートへpush してプルリクエストを作成します。レビュー担当者を必ず1名以上指定してください。

  • コミットメッセージは変更内容が分かるように書く
  • 差分（diff）はマージ前に必ず自分で見直す
Claude Code連携APIからも同じ本文を取得・更新できます（往復編集）

単元ごとに設問を登録します。種別は単一選択・複数選択・記述式から選べます。

単元3「コンフリクトの解消」に問題が1問も設定されていません

指摘
設問1（単元2）の選択肢がすべて似た形式のコマンドで紛らわしい可能性があります
「git checkout -b」以外の選択肢も実在するコマンドの断片であるため、初学者には判別が難しい場合があります。誤答選択肢の妥当性を再確認してください。
提案
本文に図解を追加すると理解しやすくなります
ブランチ分岐のイメージ図があると、テキストのみの説明より初学者の理解が進みやすいと考えられます。
