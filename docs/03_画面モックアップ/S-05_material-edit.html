AI採点・AIアシスト設定
記述式・コード記述式が対象。「手動採点」ではAIは正誤・点数を一切判定せず、S-19でプロジェクト担当者が採点します（AIは採点結果を集計してF-21のつまずき分析にのみ利用）。設問ごとにS-17でこの既定を上書きできます。
採点方式が「AI自動採点」の設問にのみ適用されます。設問ごとにS-17でこの既定を上書きできます。
記述式・コード記述式のAI採点（F-20）に反映されます。教材の作成・修正はClaude Code CLI連携（F-05）で行いますが、これは利用者自身のClaude Codeセッションでの作業であり、Manabi側からAIを呼び出すものではないため、この指示は適用されません。
受験後アンケート
回答はすべて任意でスキップ可、匿名扱いです。統計はAIが要約し、AIつまずき分析・教材改善提案（S-05「AIレビュー結果」タブ）に合流します。章ごとの設置は目次ツリーの各章ヘッダーにあるチェックボックスから行えます（第2章の例を参照）。

この教材に含まれる全ページの設問を一覧表示します。この設問を見直すべきか判断するための参照ビューで、正答率が低い・未採点が溜まっている設問ほど上に並びます。「詳細を見る」で回答の傾向（S-19）を確認できます。手動採点の未採点分を実際に採点する場合は、サイドバーの「採点」を使ってください（採点操作はそちらに一本化しています）。

指摘
設問1（第2章）の選択肢がすべて似た形式のコマンドで紛らわしい可能性があります
「git checkout -b」以外の選択肢も実在するコマンドの断片であるため、初学者には判別が難しい場合があります。誤答選択肢の妥当性を再確認してください。
提案
本文に図解を追加すると理解しやすくなります
ブランチ分岐のイメージ図があると、テキストのみの説明より初学者の理解が進みやすいと考えられます。
