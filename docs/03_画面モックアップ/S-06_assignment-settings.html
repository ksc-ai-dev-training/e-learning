配信設定

S-06

アクセス制御: admin（全スコープの配信対象を設定可能）、対象プロジェクトの管理者（自プロジェクトをスコープとする配信対象、および自分の教材の「全社任意公開」を設定可能。「全社必修配信」はadmin限定）。

全社公開プロジェクトは誰でも編集者のため、個人が配信設定なしで気軽に公開する教材が増えやすい。既定の並び順は配信設定の優先度順（全社必修配信 → 全社任意公開 → プロジェクト → 個人 → 未設定）とし、そうした教材が一覧の下に集まって全社必修配信の管理を邪魔しないようにしている。プロジェクトで絞り込むこともできる。

配信設定を編集 — 新人向けGit入門
全社・プロジェクト・個人の3種類から指定します（部署単位の配信はv1.5で廃止されました）。「全社」を選んだ場合、必修・任意の選べる範囲がロールによって変わります（下記参照）。プロジェクトの管理者は、自プロジェクトをスコープとする設定に加え、自分の教材の「全社」への任意公開も行えます。
配信対象が「全社」の場合のみ制限があります。「必修」（全社必修配信）を選べるのはadminのみで、プロジェクトの管理者が「全社」を選ぶと「任意」（全社任意公開）のみ選択でき「必修」はグレーアウトされます。一方、配信対象が「プロジェクト」（自分が管理者であるプロジェクト）の場合は、プロジェクトの管理者も必修・任意・期限をadminと同じようにフルで設定できます（自プロジェクトのメンバーへの配信のため）。
「任意」の場合は期限を設定できません
