# 検討資料

AIが作成した検討資料・計画資料の置き場。**正式な成果物（`docs/`）には含めない。**
承認されて設計に反映されたら、内容は `docs/` の該当設計書へ取り込み、ここのファイルは経緯の記録として残す。

## 規約

- ファイル名は `YYYYMMDD_タイトル.html`（または `.md`）とし、日付順に並ぶようにする
- 各資料の冒頭にステータス（検討中 / 採用 / 見送り）を明記する
- 資料を追加したら下の一覧に1行追加する
- 画面モックアップ（HTML画面そのものの検討案）は `画面モック/` 配下にまとめる。データ設計・API設計・比較資料などドキュメント寄りのものは直下に置く
