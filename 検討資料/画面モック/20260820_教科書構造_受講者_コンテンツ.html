Java研修 ／ 第1章 Java入門 ／ Javaとは？

Javaは、1995年にSun Microsystems（現Oracle）が発表したプログラミング言語です。「一度書けば、どこでも動く（Write Once, Run Anywhere）」を掲げ、OSに依存しない実行環境（JVM）上で動作することが特徴です。

主な特徴

  • オブジェクト指向言語である
  • JVM（Java Virtual Machine）上で動作するため、Windows・Mac・Linuxで同じコードが動く
  • 大規模な業務システムからAndroidアプリまで幅広く使われている

簡単なサンプルコード

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

このコードを実行すると、コンソールに「Hello, Java!」と表示されます。次のページから、実際に開発環境をセットアップしていきます。
